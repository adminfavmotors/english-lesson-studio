# A Better Life · Lesson Studio

Интерактивный урок английского по Unit 14, страницам 128–129. React + TypeScript + Vite; обычный CSS. Локальная практика работает без интернета после установки зависимостей. Для общей сессии между браузерами и компьютерами подключена отдельная бесплатная база Supabase `english-lesson-studio` в организации `favmotors`.

## Запуск в Windows / PowerShell

Нужен Node.js 22.18+ или 24 LTS. В этой среде установлен Node.js 24.12.0, зависимости уже установлены.

```powershell
Set-Location -LiteralPath 'H:\проект для англ'
npm run dev -- --port 5173 --strictPort
```

Открыть http://127.0.0.1:5173/ . Остановить сервер: Ctrl+C в его терминале. Если порт занят уже работающим экземпляром этого проекта, использовать открытую страницу; для другого порта поменять значение `--port`.

На другом компьютере после копирования исходников сначала выполнить `npm ci` с подключением к интернету. После установки интернет не требуется для локальной практики. Общая сессия требует интернета; локальный сервер должен продолжать работать, пока приложение не опубликовано на хостинге. Не открывать `index.html` двойным щелчком.

```powershell
npm run build
npm run preview -- --port 4173 --strictPort
npm test
```

`build` проверяет TypeScript и создаёт папку `dist`. `preview` открывает собранную версию на http://127.0.0.1:4173/ . В локальном режиме прогресс привязан к origin браузера. В общей сессии ответы сохраняются в Supabase и восстанавливаются по той же ссылке независимо от браузера, компьютера и адреса frontend.

## Локальная практика и две вкладки

- Ученик: http://127.0.0.1:5173/?mode=student#vocabulary
- Преподаватель: http://127.0.0.1:5173/?mode=teacher#vocabulary

Из ученической версии можно переключиться в Teacher сверху; в панели преподавателя ссылка **Открыть версию ученика** открывает отдельную вкладку. Вкладки должны быть открыты в одном браузере и профиле, с одинаковым адресом и портом. Ответы, отметки, оценки, скрытие текста и состояние таймера синхронизируются через `BroadcastChannel` и события `localStorage`. Раздел, выбранная роль и раскрытый ключ ответов остаются локальными для вкладки. Это описание локального режима без параметра `session`. В общей сессии права определяются приглашением и проверяются базой данных, переключение Teacher / Student заблокировано.

В кабинете учителя слева находится меню сервиса **Ученики / Задания**. «Ученики» показывает карточку ученика текущего индивидуального занятия; общий список нескольких учеников пока не добавлен. «Задания» открывает материалы урока. Выбор вкладки хранится в адресе (`view=students` / `view=assignments`) и восстанавливается после обновления. Справа расположены приглашение и просмотр ученической версии, выбор раздела, таймер, раскрываемые данные ученика и занятия, календарь, прогресс и проверка ответов. На узком экране управление открывается правой кнопкой в шапке. Ученическая навигация и раскладка сохранены.

Ответы сохраняются при каждом изменении. Отметка **Correct / Needs improvement** относится к конкретному ответу и снимается при его редактировании. Сброс отдельного упражнения и всего урока доступен преподавателю с дополнительным подтверждением внутри интерфейса. Сброс распространяется на все подключённые устройства общей сессии, а в локальном режиме — на вкладки одного браузера.

## Общая сессия на разных устройствах

1. Открыть приложение в режиме **Teacher**.
2. Заполнить **Student & lesson**: имя, уровень, название и номер занятия. В правой панели выбрать дату, время и длительность.
3. Нажать **Invite student → Create shared lesson**. Данные занятия и настройки таймера переносятся; упражнения начинают с пустыми ответами.
4. Скопировать **Student invitation** и передать ученику.
5. Через **Save my teacher link** сохранить собственную преподавательскую ссылку. Эта ссылка открывает тот же урок на другом компьютере с преподавательскими правами.
6. Для продолжения открывать прежние ссылки, а не создавать каждый раз новую сессию.

Ученическая ссылка позволяет писать ответы, запускать таймер, отмечать выполнение и повторять Exercise 1. Оценки, скрытие текста Reading и сброс остальных упражнений доступны только преподавательской ссылке. Подмена `mode=student` на `mode=teacher` не повышает права: роль возвращает база по секрету приглашения.

Полная ссылка является доступом к сессии. Секрет расположен после `#` и передаётся базе в заголовке запроса, а не в query-параметрах сервера frontend. Преподавательскую ссылку следует хранить у себя; ученику предназначена отдельная ссылка.

Видимые изменения отправляются после короткой паузы ввода; второе активное окно проверяет изменения каждую секунду, фоновое — каждые четыре секунды. Это HTTP-синхронизация с коротким опросом, без WebSocket. Обновления обычно появляются в течение 1–2 секунд в активном окне. Пока версия урока не менялась, база возвращает только метаданные, без полного документа.

При потере сети работа помещается в локальную очередь и отправляется после восстановления связи. Очередь сохраняется при обновлении той же вкладки, если хранилище браузера доступно. Ответы разных упражнений не перезаписывают друг друга. Одновременное редактирование одного поля разрешается по порядку поступления на сервер; совместного редактирования текста по символам здесь нет.

## Публикация на Vercel

Для ссылки, доступной с другого компьютера, frontend нужно опубликовать. Адреса `localhost` / `127.0.0.1` открывают локальный компьютер получателя и не являются публичными приглашениями. После публикации новые приглашения автоматически будут содержать публичный домен.

Загрузить исходники и `package-lock.json` на GitHub, импортировать репозиторий в Vercel:

- Framework Preset: **Vite**.
- Build Command: `npm run build`.
- Output Directory: `dist`.
- Install Command: `npm ci`.
- Root Directory: корень, если исходники лежат в корне репозитория.

Настройки подключения уже находятся в `src/backend.config.ts`; секретных серверных ключей и дополнительных переменных окружения для текущего подключения не требуется. Это публичный publishable key, безопасность данных обеспечивается приглашениями и SQL-проверками. Миграции уже применены к подключённому проекту, повторно запускать их при публикации не нужно.

`npm test` запускает локальные тесты без интернета. `npm run test:cloud` отдельно проверяет настоящую базу: создаёт тестовую сессию, проверяет запись, роли, изоляцию и сброс; в конце очищает ответы этой тестовой сессии.

## Что реализовано

- 1: пять вопросов a/b, нейтральный выбор до проверки, результат из пяти, подсветка верного и неверного вариантов, повтор и ключ ответов преподавателя.
- 2: индивидуальная практика Review → Recall → Self-check. Пять исходных пар, устный или письменный ответ по одной карточке, раскрытие оригинала, самооценка и повтор только трудных карточек. Двухминутный таймер на этапе Review необязателен.
- 3–4: письменные ответы, пример диалога, заметки для устной работы и отметка выполнения.
- 5–9: обсуждение, текст Maja, девять вопросов и отдельные ответы Student A / B, заметки и пошаговое интервью по вопросам Exercise 6 с переключением спрашивающего.
- 10–11: исходный блок грамматики, вопросы к текстам и пять свободных дополнений. Преподаватель оценивает ответы вручную.
- 12: шесть тематических карточек с заметками.
- 13–14: место для оригинальных аудиозаписей, стандартный аудиоплеер при наличии файла, восемь полей диктанта и восемь слов-подсказок. Автоматической проверки аудирования и устной речи нет.
- Просмотр оригинального изображения в диалоге и открытие его в полном размере.

## Структура

```text

src/store.ts        Переключение между локальным хранилищем и общей сессией
src/store-model.ts  Типы и слияние локальных документов
src/session-api.ts  RPC API базы, разбор приглашений и навигация

src/SessionPanel.tsx Создание сессии, ссылки и состояние подключения
src/LessonWorkspace.tsx Карточка ученика, календарь и общий таймер

public/audio/      Оригинальные записи, добавляемые позднее

VERIFICATION.md    Выполненные проверки и границы проверки
```

Описание упражнения (`Exercise`) хранится отдельно от состояния пользователя. Все упражнения имеют общий ID, номер, раздел, инструкцию и дискриминирующий `type`; конкретный тип задаёт содержимое и правила проверки. Ответы, оценки и завершённость адресуются ключами `<exerciseId>.answer.<questionId>`, `<exerciseId>.answer.<questionId>.grade` и `<exerciseId>.complete`. Для парной работы ключ дополнен ролью.

Слияние выполняется по полям с логическим временем и идентификатором вкладки. Правки разных полей объединяются; при одновременном редактировании одного поля выигрывает более поздняя запись, при равном времени — стабильный порядок идентификаторов. Сброс сохраняет пустые записи, чтобы старое состояние другой вкладки не восстанавливало ответы.

В общей сессии порядок правок назначает сервер, а не часы компьютеров. Одновременные правки разных полей сохраняются независимо; для одного поля выигрывает последняя полученная сервером правка. Версия сброса хранится отдельно для каждого упражнения: старая очередь не восстанавливает сброшенные ответы.

Для следующего учебника можно добавить структурированные данные с теми же типами и подключить их к оболочке. Это ручная оцифровка урока; универсального конвертера изображений здесь нет.


## Обновлённое рабочее пространство занятия

- **Шрифт:** локальный Source Sans 3 с поддержкой кириллицы. Инструкции и ответы 16–18 px, текст Reading 18 px, обычный шрифт без декоративных засечек.
- **Teacher:** синяя цветовая тема, редактируемая карточка Student & lesson и панель Session controls справа.
- **Student:** зелёная тема, приветствие, данные текущего занятия и общий таймер без управления им.
- **Данные:** имя и уровень ученика, название и номер занятия. Это данные одной сессии, а не отдельная CRM или каталог учеников.
- **Календарь:** выбор даты текущего занятия, переходы между месяцами, ввод даты и времени. Это внутреннее расписание текущей сессии, без интеграций с внешними календарями. Часовой пояс подписан: Europe/Warsaw.
- **Общий таймер:** преподаватель задаёт длительность от 1 до 240 минут (по умолчанию 60), запускает, ставит на паузу, продолжает и сбрасывает. Таймер отображается также в закреплённой верхней панели. Ученик видит тот же отсчёт и состояние; управление закрыто как в интерфейсе, так и в SQL API.
- **Exercise 2:** собственный таймер упражнения на две минуты сохранён отдельно от общего таймера урока.
- **Сброс ответов:** очищает упражнения и их прогресс, сохраняя данные ученика, дату, время и общий таймер.
- **Узкое окно:** навигация открывается кнопкой меню, а календарь и таймер — через Open session controls. Панели закрываются Escape; Tab остаётся внутри открытой панели.

Данные и таймер хранятся в полях `lesson.*` того же документа Supabase. В приложении используется поправка на время сервера, чтобы разные часы компьютеров не давали разный отсчёт. При редактировании нескольких учительских вкладок настройки разрешаются по порядку получения базой, как и другие поля.


## Exercise 2 — практика для одного ученика

Задание адаптировано из исходной парной работы. Исходная инструкция сохранена в свёрнутом блоке Original textbook instruction. Все пять фраз и соответствующих утверждений взяты из Exercise 1.

1. **Review:** ученик изучает пять пар предложений в своём темпе. При желании включает двухминутный таймер. Его истечение переводит к карточкам, но ждать его окончания не требуется.
2. **Recall:** показывается одна фраза, соответствующее утверждение скрыто. Ученик вспоминает его вслух или записывает ответ; поле необязательное.
3. **Reveal answer:** открывает исходное утверждение. Дословное совпадение не требуется — ученик сопоставляет смысл.
4. **I remembered / Practise again:** самооценка переводит к следующей карточке.
5. **Self-check:** итог по пяти карточкам и возможность повторить только отмеченные трудными или все карточки. Start over возвращает к этапу Review.

Письменный ответ, текущая карточка, раскрытие и самооценки сохраняются. В общей сессии преподаватель видит тот же этап работы через Supabase. Состояние практики хранится в `<exerciseId>.memory.*`, письменные ответы — в `<exerciseId>.answer.recall.*`. Ученик может перезапустить только Exercise 1 и Exercise 2; остальные права преподавателя сохранены. Общий таймер урока работает независимо.
